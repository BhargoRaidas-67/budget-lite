# Simple Budget Tracker

A lightweight, manual budget tracker written in Python. This project is specifically designed for beginners, focusing on clean logic and readability.

## Features
* **Manual Input:** Add expenses one by one at your own pace.
* **Live Updates:** Displays your total spending after every entry.
* **Limit Alerts:** Automatically warns you if you exceed your target budget.
* **No Clutter:** Built without complex functions, underscores, or comments for maximum simplicity.

## How to Run
1. Download the Python script file.
2. Open your terminal or command prompt.
3. Run the program using:
   `python filename.py`
4. Enter your budget limit and follow the on-screen prompts!
